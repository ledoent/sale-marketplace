# Sale Marketplace

Marketplace connectors for Odoo, built on the OCA `sale_channel` base.

A generic `sale_marketplace` tier adds the cross-marketplace primitives that
`sale_channel` lacks (per-channel external product/SKU binding), and
marketplace-specific families (`sale_marketplace_amazon*`) mount on top.
