This module pulls Amazon FBA inventory (FBA Inventory API,
getInventorySummaries) into per-SKU records and surfaces the drift
between Amazon's fulfillable quantity and the matching Odoo product's
on-hand quantity at the channel warehouse.

A scheduled action (*Amazon: Sync FBA Inventory*, disabled by default)
refreshes the FBA inventory snapshot per channel.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_
