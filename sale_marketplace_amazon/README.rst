This module turns a ``sale.channel`` into an **Amazon Selling Partner
API** marketplace channel. It registers the ``amazon`` channel type and
adds the SP-API connection configuration (LWA credentials, marketplace,
seller id, fulfilment warehouse, sandbox toggle) plus a *Test
Connection* action.

It only provides the channel + client wiring. Order import, listings,
inventory and tracking are provided by the ``sale_marketplace_amazon_*``
modules built on top.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Configuration
=============

To connect an Amazon seller account:

1. Go to *Sales > Configuration > Sale Channels* and create a channel.
2. Set *Channel Type* to **Amazon**.
3. Fill the *Amazon SP-API* section: LWA Client ID, Client Secret and
   Refresh Token (from your SP-API application), the *Marketplace*, your
   *Seller ID* (Seller Central merchant token) and the *Warehouse* that
   fulfils this channel.
4. Tick *Sandbox Mode* while testing against Amazon's SP-API sandbox.
5. Click *Test Connection* to verify the credentials.

Credentials are stored in fields restricted to the *Settings* group.
